How it works

K2 Emulator is a frontend for EmulatorJS. Select a compatible game file, confirm its system, and launch it in the built-in player.

What is stored

Imported files, favorites, names, and recent-play information are stored locally in this browser using IndexedDB and local storage. Clearing browser site data removes them.

Legal use

No ROMs, BIOS files, firmware, keys, or copyrighted game artwork are included. Only use files you are legally permitted to possess and play.

Compatibility

Performance depends on the browser, device, emulator core, and game. Desktop Chromium-based browsers generally provide the broadest compatibility. iPhone and iPad browsers may reload large games when memory is limited.
